# Halsted 人物时间线 — 详细版

## 早年与教育（1852–1880）

| 年份 | 事件 |
|------|------|
| 1852年9月23日 | 生于纽约市，父亲是纺织商人 |
| 1870–1874 | 就读耶鲁大学，对自然科学感兴趣，但成绩平平 |
| 1874–1877 | 哥伦比亚大学内外科医师学院，医学博士 |
| 1877–1878 | 贝尔维尤医院实习（纽约） |
| 1878–1880 | 赴欧洲留学：维也纳（师从Billroth）、哈雷（师从Volkmann）、莱比锡、柏林 |

**欧洲留学的关键影响**：
- Theodor Billroth（维也纳）：胃切除术先驱，强调解剖知识和系统记录
- Richard von Volkmann（哈雷）：将无菌技术系统化，强调组织轻柔处理
- 德国住院医师制度：给了Halsted建立美国版本的蓝图

## 纽约时期与可卡因危机（1880–1888）

| 年份 | 事件 |
|------|------|
| 1880 | 返回纽约，在多家医院任职，声誉迅速上升 |
| 1882 | 为母亲紧急输血（抽自己的血）——早于现代输血技术的临床应用 |
| 1884 | 读到Koller关于可卡因局麻效果的报告，开始自我实验 |
| 1885 | 与同事共同发表可卡因神经阻滞研究论文，但多名参与者成瘾 |
| 1886 | 因严重成瘾，被送往罗德岛疗养院 |
| 1886–1887 | 疗养期间转为吗啡依赖（作为治疗手段引入） |
| 1887–1888 | 在William Welch帮助下，逐渐恢复工作能力 |

---

## 约翰斯·霍普金斯时期（1889–1922）

| 年份 | 事件 |
|------|------|
| 1889 | 受William Welch邀请，成为约翰斯·霍普金斯医院外科主任（临时职位） |
| 1890 | 引入橡皮手套；与护士Caroline Hampton相识 |
| 1890 | 与Caroline Hampton结婚 |
| 1892 | 正式获得约翰斯·霍普金斯外科学教授职位 |
| 1894 | 发表根治性乳房切除术论文 |
| 1898 | 正式建立住院医师培训项目 |
| 1904 | 发表腹股沟疝修补论文（Halsted II手法） |
| 1910年代 | 学生Harvey Cushing建立神经外科，Hugh Young建立泌尿外科 |
| 1918 | 发表甲状腺手术技术论文 |
| 1922年9月7日 | 因胆管手术后并发症去世，享年70岁 |

## 死后影响时间线

| 年份 | 事件 |
|------|------|
| 1930年代 | 美国外科学会采纳Halsted式住院医师培训为全国标准 |
| 1952 | Samuel Crowe出版《Halsted of Johns Hopkins》，首次系统整理其生平 |
| 1970年代 | 乳腺癌外科进入保乳时代，Halsted根治术逐渐被改良根治术取代 |
| 2010 | Gerald Imber出版《Genius on the Edge》，详述成瘾史和个人生活 |
| 至今 | "Halstedian principles"仍是全球外科教科书的核心章节 |
